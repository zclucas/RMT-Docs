### 功能说明
围绕时间控制宏的执行。当前编辑器提供「等待」「区间判断」「倒计时」三种类型。

### 类型说明
1. **等待**：等待某个时刻、指定时长或时间戳到达，再执行后续指令。
2. **区间判断**：检查当前时间是否位于开始与结束时间之间；不满足时可选择跳过本条判断、等待进入区间或终止宏。
3. **倒计时**：显示倒计时浮层，并选择是否等待倒计时结束后再继续执行。

### 参数解析
1. **时刻**：按时、分、秒设置目标；日期范围可使用时间戳类型。
2. **时长**：按界面中的时长参数设置等待或倒计时时间。
3. **时间戳**：使用对应的时间值或变量设置目标、区间起止。
4. **检测间隔 / 超时**：等待类型使用；单位毫秒，超时 `0` 表示无限等待。
5. **不满足时**：区间判断类型使用，可选跳过、等待或终止。
6. **等待结束**：倒计时类型使用；「不等待」时后续指令可立即继续。
7. **显示坐标 X / Y**：倒计时浮层的位置，可用 F1 取点。

### 特别说明
- 区间判断的「跳过」表示结束本条判断并继续后续指令，不会自动跳过一整段宏；需要条件分支时使用「如果」或「如果Pro」。
- 时刻区间支持跨午夜，例如 `22:00:00` 到 `06:00:00`。
- 旧配置中的获取时间变量、获取时间字符串和时间计算仍有执行兼容；当前编辑器不再将它们列为可新建的类型。
- 旧版独立的「倒计时」指令由本编辑器兼容处理，左侧不再单独列出。

### 指令格式
- 参数保存在配置中，宏中写 `时间序号` 或 `时间序号_备注`。
- 示例：`时间1`、`时间1_等待整点`
