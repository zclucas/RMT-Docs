所属分类：输入/输出

**指令界面**

![配置界面](/img/latest/MacroCMD/Input.png)

### 功能说明
1. **写入变量**：弹出输入框或真 / 假按钮，把用户的选择保存到变量，供后面的指令使用。
2. **控制流程**：用按钮让宏在这里停一下等人操作，确认后继续，或取消并终止。

### 类型说明
1. **弹窗**：弹出输入框，把用户输入的内容写入变量。适合问数量、名字这类需要打字的场合。
2. **状态**：弹出真 / 假两个按钮。选真写入 `1`，选假写入 `0`。适合让人做一次是否判断。
3. **继续**：只弹出一个继续按钮，点了之后才执行后面的指令。适合「确认后再往下走」。
4. **继续&取消**：弹出继续和取消。点继续则往下执行；点取消则按「取消时」的规则终止宏。

### 参数解析
1. **类型**：弹窗 / 状态 / 继续 / 继续&取消。
2. **交互时**：窗口开着时，其它正在跑的宏怎么办。无论选哪一项，本条都会等到窗口关掉才继续后面的指令。选「暂停所有宏」时，其它宏也会先停住，关掉窗口后再恢复。
3. **取消时**：仅「继续&取消」使用。点取消时，是只终止当前这条宏，还是终止所有正在跑的宏。
4. **保存变量**：仅「弹窗」「状态」使用，用来存放输入内容或 `1` / `0`。
5. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **快捷键**：回车视为真值或继续；Esc 视为假值或取消。
2. **Enter 不误触**：输入弹窗打开期间，Enter 触发键会被暂时禁用，避免回车把别的宏触发了。
3. **关掉才继续**：窗口还开着时，本条后面的指令不会执行。关掉窗口后才会继续。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`输入序号`，带备注时为 `输入序号_备注`
- 示例：`输入1`、`输入1_问数量`
