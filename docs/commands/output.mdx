**指令界面**

![配置界面](/img/latest/MacroCMD/Output.png)

### 功能说明
1. **输出信息**：按选定方式把文本发给目标程序、屏幕或系统。
2. **替换变量**：内容里的变量、数组会在执行时先替换成当前值，再输出。

### 类型说明
1. **发送内容**：用 AHK `SendText` 逐字发送到当前焦点处，像在键盘上打字。
2. **粘贴内容**：先把内容写入剪贴板，再按 Ctrl+V 粘贴。游戏里发送无效时可以改用这项。
3. **临时提示**：在鼠标旁边显示一小段提示（默认大约 5 秒），不发给其它程序。
4. **指令窗口**：写到软件自己的指令显示窗口里，方便调试。
5. **软件弹窗**：弹出软件对话框，需要人点掉才会继续。
6. **系统语音**：用系统语音把内容读出来。
7. **复制到剪切板**：只写入剪贴板，不会按 Ctrl+V，也不会弹窗。

### 参数解析
1. **输出类型**：上面七种之一。
2. **输出内容**：要发送的文本。`{变量名}` 会替换成该变量的当前值，`{ε数组名}` 会展开成数组内容。
3. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **发送与粘贴**：游戏里 `SendText` 可能无效。可以改成「粘贴内容」，或先确认该条宏的按键类型、是否已管理员启动。
2. **指令窗口**：需要先在设置里开启「指令显示」，否则这里输出了也看不到。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`输出序号`，带备注时为 `输出序号_备注`
- 示例：`输出1`、`输出1_打招呼`
