title: "9 手柄检测"
sidebar_position: 10
---
所属分类：键鼠/手柄

### 功能说明
1. **读手柄状态**：检测手柄按钮、方向键、摇杆或扳机当前是不是按下 / 达到设定轴值。
2. **写入变量**：符合检测条件时写入 `1`，否则写入 `0`。本指令自己不会输出任何手柄动作。
3. **选键方式**：与「手柄」指令相同，在手柄图上点击按键组合，可拖动摇杆设定检测轴值；也可直接按真实手柄按键或推动摇杆自动选中。

### 类型说明
1. **按钮**：同时按下 / 有一个按下。按钮与摇杆不能同时检测。
2. **摇杆**：大于设定值 / 大于等于 / 等于设定值 / 小于等于 / 小于设定值。各轴都按同一比较方式相对设定值判断，全部满足才为 `1`。

### 参数解析
1. **手柄按键**：在手柄图上选择要检测的按钮、方向键；拖动摇杆 / 扳机设检测轴值。
2. **检测模式**：按钮为同时按下 / 有一个按下；摇杆为与设定值的比较方式。
3. **检测类型**：
   - **物理状态**：真实手柄上的按下。
   - **逻辑状态**：物理按下，或本软件宏指令模拟出来的按下。
4. **结果变量**：用来存放 `1` 或 `0`。

### 特别说明
1. **和手柄指令**：本指令只读取状态，不会通过 ViGEm 输出。
2. **配合如果**：把结果变量交给「如果」去判断，就可以按「现在有没有按住该手柄键」走不同分支。
3. **未选手柄键**：列表为空时，本条不会写入变量。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`手柄检测序号`，带备注时为 `手柄检测序号_备注`
- 示例：`手柄检测1`、`手柄检测1_是否按住A`
