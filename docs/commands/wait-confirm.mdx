所属分类：流程

### 功能说明
弹出提示，等待用户决定继续、终止或暂停宏。适合在关键步骤前人工检查，也可配置超时后的动作。

### 类型说明
1. **继续**：显示用于继续执行的确认界面。
2. **继续&终止&暂停**：提供继续、终止和暂停操作。

### 参数解析
1. **提示**：显示给用户的说明文字，可引用变量。
2. **交互时**：只暂停当前宏，或在交互期间暂停所有宏。
3. **超时(ms)**：等待上限，`0` 表示不设置超时。
4. **超时后**：无、自动继续、自动终止或自动暂停。
5. **终止 / 暂停范围**：分别指定按钮操作针对当前宏还是所有宏。
6. **备注**：便于辨认这条人工确认步骤。

### 特别说明
- 点击继续后恢复执行；选择终止或暂停时按配置的范围处理。
- 交互期间暂停所有宏时，继续后会恢复相关宏；终止或暂停操作则按所选范围处理。
- 需要用户输入文本或选项时使用「输入」，本指令负责确认与执行控制。

### 指令格式
- 参数保存在配置中，宏中写 `等待确定序号` 或 `等待确定序号_备注`。
- 示例：`等待确定1`、`等待确定1_确认提交`
