### 功能说明
在同一条指令中配置多个搜索目标，按「满足个数」判断本轮搜索是否成功。各目标可分别使用图片、颜色或文本搜索，也可分别选择屏幕或窗口搜索。

### 参数解析
1. **目标列表**：添加、删除并选择当前编辑的目标。每个目标独立设置搜索类型、窗口信息、范围、目标内容、相似度和识别模型。
2. **满足个数**：选择「所有」表示全部目标都要找到；填写正整数表示找到至少这么多个目标即可。统计的是满足条件的目标条目数。
3. **搜索次数 / 每次间隔**：设置最多尝试的轮数与轮次之间的等待；选择无限时持续尝试，直到满足或宏被终止。
4. **鼠标动作**：整体条件满足后，对本轮已收集的找到位置执行所选动作；屏幕目标和窗口目标使用各自对应的动作方式。
5. **结果保存 / 目标点保存**：将成功或失败的值、找到位置的坐标写入指定变量。
6. **找到后 / 未找到后**：整体成功或有限次数用尽仍未成功时执行对应分支，两段都可留空。

### 特别说明
- 每轮按目标列表顺序搜索，达到满足个数后就结束本轮，不保证继续搜索后面的目标。
- 整体条件满足后，「找到后」分支只执行一次；有多个位置时，同一组坐标变量会依次写入，最终保留最后写入的位置。
- 框选范围、截图和取色作用于当前选中的目标。切换目标后检查对应参数，避免把某个目标的范围填到另一个目标上。
- 只查一个目标时优先使用「搜索」或「搜索Pro」。旧版多目标搜索Pro可在本编辑器中继续编辑。

### 快捷键
- **F1**：框选当前目标的搜索范围。
- **F2**：为当前目标截图。
- **F3**：取色。

### 指令格式
- 参数保存在配置中，宏中写 `搜索Combo序号` 或 `搜索Combo序号_备注`。
- 示例：`搜索Combo1`、`搜索Combo1_检查多个按钮`
