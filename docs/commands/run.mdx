**指令界面**

![配置界面](/img/latest/MacroCMD/Run.png)

### 功能说明
1. **打开目标**：运行文件、进程、脚本，或用系统默认方式打开网址。启动后立刻继续后面的指令。
2. **只要备注和目标**：需要等待返回值、标准输入输出、窗口显示方式时，请用「运行Pro」。

### 参数解析
1. **目标**：要运行的路径 / 网址 / 命令行。内容里的 `{变量名}` 会先替换再执行。
2. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **路径空**：目标为空或替换后仍为空时，本条会失败，不会启动任何东西。
2. **窗口**：简化版固定以默认窗口启动、不等待结束。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`运行序号`，带备注时为 `运行序号_备注`
- 示例：`运行1`、`运行1_打开记事本`
