### 功能说明
读取或写入文本文件，可将读取结果保存到变量或数组。Excel 工作簿使用左侧单独的「Excel」指令。

### 类型说明
1. **读取全部内容**：将整个文件读入变量。
2. **逐行读取**：从指定行开始，将后续各行读入数组。
3. **读取指定行**：将某一行内容读入变量。
4. **覆盖写入**：清空原内容后写入。
5. **追加写入**：接在文件末尾，不自动换行。
6. **追加写入-行**：先换行，再追加内容。
7. **写入指定行**：改写某一行，行数不足时补空行。
8. **行号自增**：从指定行向下寻找空行写入，必要时在末尾新增一行。

### 参数解析
1. **文件路径**：要读写的目标文本文件。
2. **编码**：文件的文本编码，默认 UTF-8，需与实际文件编码一致。
3. **操作模式 / 行号**：按读取或写入需求选择模式，行号从 1 开始。
4. **写入内容**：要写入文件的文本。
5. **保存类型 / 名称**：指定读取结果保存到的变量或数组。
6. **备注**：便于辨认指令。

### 特别说明
- 覆盖写入会清空原内容，执行前检查目标路径。
- 文本文件与 Excel 的参数不同；旧配置中的 Excel 操作应使用「Excel」入口编辑。

### 指令格式
- 参数保存在配置中，宏中写 `文件读写序号` 或 `文件读写序号_备注`。
- 示例：`文件读写1`、`文件读写1_读配置`
