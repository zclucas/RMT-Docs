**指令界面**

![配置界面](/img/latest/MacroCMD/IfPro.png)

### 功能说明
1. **多分支**：从上往下逐条判断，执行第一条条件成立的分支，后面的不再看。
2. **默认分支**：上面所有分支都不成立时，执行「以上都不是」。

### 类型说明
1. **分支条件**：每一条分支内部可以有多路判断，比较方式和「如果」相同；同一条分支内部再用且 / 或把多路拼起来。
2. **以上都不是**：上面一条都没匹配上时的兜底。也可以留空，表示都不中就什么都不做。

### 参数解析
1. **分支列表**：每一条独立设置条件与分支指令；需要控制循环或退出分支时，在指令中添加「跳转」。
2. **默认分支**：「以上都不是」时执行的指令，也可以添加「跳转」。
3. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **只走一条**：命中第一条后，后面的分支即使也成立，也不会执行。要把更特殊的情况放上面，更宽的条件放下面。
2. **分支右键**：在分支上右键可以编辑、向上 / 向下插入、上移（提高优先级）、下移、删除。
3. **和如果**：只有「成立 / 不成立」两路时，用「如果」更简单。需要按多种状态分流时，再用本指令。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`如果Pro序号`，带备注时为 `如果Pro序号_备注`
- 示例：`如果Pro1`、`如果Pro1_状态机`
