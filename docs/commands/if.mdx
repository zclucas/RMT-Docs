**指令界面**

![配置界面](/img/latest/MacroCMD/If.png)

### 功能说明
1. **条件分支**：按判断结果执行「成立」或「不成立」那一段指令。两段都可以留空，只判断、不分支。
2. **条件跳转**：需要跳过循环、跳出循环或结束分支时，在对应分支中添加「跳转」指令。

### 类型说明
1. **大于 / 大于等于 / 等于 / 不等于 / 小于等于 / 小于**：比较左右两边的数值。
2. **字符包含**：左边这段文字里，是否包含右边这段文字。
3. **变量存在**：左边这个变量名当前是否已经存在。
4. **正则表达式**：左边的变量或值，是否匹配右边的正则。

### 参数解析
1. **判断**：可添加任意数量；每一路可以单独开关。左值一般填变量名，右值可以是变量名或直接写的数字 / 文字。
2. **逻辑关系**：「且」表示已启用的条件全部成立才算成立；「或」表示有一路成立就算成立。
3. **分支指令**：「成立后」和「不成立后」两段都可以留空。
4. **结果保存**：勾选后，把这次判断的真值或假值写入指定变量，方便后面再用。
5. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **执行顺序**：先写入结果变量，再执行对应分支里的指令。分支可以使用刚保存的结果；独立跳转指令执行到所在位置时立即生效。
2. **跳转指令的动作**：
   - **循环-跳过本轮**：立刻结束本轮循环体剩下的指令，进入下一轮。
   - **循环-跳出**：离开当前这一层「循环」指令。如果当前并不在循环指令里，则会结束整条宏的外层循环。
   - **分支-跳出**：跳过当前这一层还没执行的指令（例如搜索 / 如果分支里剩下的部分），然后回到上一层继续。在分支内使用时会回到外层继续；顶层使用时结束本轮剩余指令。
3. **和如果Pro**：本指令是一组条件、真假两条路。需要按优先级走多条不同分支时，用「如果Pro」。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`如果序号`，带备注时为 `如果序号_备注`
- 示例：`如果1`、`如果1_血量不足`
