### 功能说明
读取或写入 Excel 工作簿，支持单元格、行、列和指定区域。与「文件读写」共用底层读写能力，使用单独的 Excel 参数界面。

### 类型说明
1. **读取单元格**：读取指定格子，保存到变量。
2. **读取指定行 / 指定列**：从起始格子沿行或列读取，保存到数组；遇到连续空格达到停止条件时结束。
3. **读取指定区域-行 / 指定区域-列**：按起止行列读取矩形区域，并按所选行列方向组织结果。
4. **写入单元格**：将内容写入指定格子。
5. **行号自增 / 列号自增**：从指定格子向下或向右寻找空格写入。
6. **写入指定区域-行 / 指定区域-列**：将数组按行或列方向写入区域；一维数组可写成一行或一列。

### 参数解析
1. **文件路径**：目标 `.xlsx` 或 `.xls` 工作簿。
2. **表名或序号**：工作表名称或从 1 开始的工作表序号。
3. **行 / 列**：起始单元格位置；区域读取还需填写结束行、结束列，可使用变量。
4. **内容 / 数组**：单格写入使用内容，行列或区域写入使用数组。
5. **保存类型 / 名称**：单元格读取保存到变量，行列及区域读取保存到数组。
6. **备注**：便于辨认指令。

### 特别说明
- 需要本机具备可用的 Excel 自动化环境。
- 指定区域可以是单行或单列；只读取一个格子时使用「单元格」模式。跨行跨列读取时，结果为二维数据。
- 写入已在 Excel 中打开的工作簿通常更快；先用副本确认行列与写入范围。

### 指令格式
- 参数保存在配置中，宏中写 `Excel序号` 或 `Excel序号_备注`。
- 示例：`Excel1`、`Excel1_读取订单`
