**指令界面**

![配置界面](/img/latest/MacroCMD/Run.png)

### 功能说明
1. **打开目标**：运行文件、进程、脚本，或用系统默认方式打开网址。
2. **可等待**：可以选择等它结束，再把退出码或输出写入变量。

### 类型说明
1. **不等待**：启动后立刻继续后面的指令，不管目标什么时候结束。
2. **等待+返回值**：等到进程结束后，才继续后面的指令，并把退出码写入变量。
3. **不等待+输入**：启动时把「标准输入」写给目标程序，然后不等待结束。
4. **等待+输入输出**：启动时写入标准输入，等到结束，再把退出码、标准输出、标准错误分别写入变量。

### 参数解析
1. **路径 / 网址**：要运行的目标。内容里的 `{变量名}` 会先替换再执行。
2. **窗口选项**：启动后窗口怎么显示：后台（隐藏）/ 默认 / 最小化 / 最大化。
3. **标准输入**：仅「不等待+输入」「等待+输入输出」使用，相当于往程序里预先喂一段输入。
4. **结果变量**：「等待+返回值」只写一个退出码；「等待+输入输出」依次写退出码、标准输出、标准错误。
5. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **路径空**：目标为空或替换后仍为空时，本条会失败，不会启动任何东西。
2. **编码**：带输入输出的两种类型，可以分别指定标准输入 / 标准输出 / 标准错误的编码，避免中文乱码。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`运行Pro序号`，带备注时为 `运行Pro序号_备注`
- 示例：`运行Pro1`、`运行Pro1_打开记事本`
