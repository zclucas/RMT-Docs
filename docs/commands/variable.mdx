所属分类：变量/数据

**指令界面**

![配置界面](/img/latest/MacroCMD/Var.png)

### 功能说明
1. **读写变量**：给变量赋值、取随机数、写入字符串、读取系统变量，或删除变量。
2. **全局共享**：这里创建的变量都是全局变量，所有宏都能读写同一个名字。

### 类型说明
1. **数值**：把一个数字，或另一个变量的当前值，赋给目标变量。
2. **随机数值**：在最小值和最大值之间随机取一个数，赋给目标变量。
3. **字符**：把一段字符串赋给变量。
4. **系统**：读取系统内置变量的当前值，写到目标变量里。系统变量本身是只读的，赋回去也改不了它。
5. **删除**：删掉指定变量。变量本来就不存在时，这一路没有效果。

### 参数解析
1. **变量存在忽略**：勾选后，如果目标变量已经有了，这一路不再改它。适合做「只在第一次初始化」。
2. **开关**：最多 4 路同时配置。没勾选的路不会执行。
3. **变量名**：不能为空、不能是纯数字、不能包含 `_`（下划线和指令参数分隔符冲突）。
4. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **系统变量只读**：不能把系统变量当作赋值目标，这样写不会生效。
2. **无变量提醒**：后面的指令引用了不存在的变量时，要不要弹窗，由设置「无变量提醒」决定。关了提醒时，看起来会像那条指令没执行。
3. **系统变量一览**：
   - **循环次数**：最近一层「循环」指令的当前轮次
   - **宏循环次数**：该条宏外层已执行的轮次（从 1）
   - **句柄ID**：当前鼠标所在窗口句柄
   - **当前鼠标颜色**：如 `EEFF44`
   - **当前鼠标坐标X / Y**：屏幕坐标
   - **当前日期**：如 `2026-04-12`
   - **当前时间**：如 `19:46`
   - **当前时间(秒)**：如 `19:46:58`
   - **当前秒**：如 `58`
   - **当前星期几**：系统星期

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`变量序号`，带备注时为 `变量序号_备注`
- 示例：`变量1`、`变量1_初始化HP`
