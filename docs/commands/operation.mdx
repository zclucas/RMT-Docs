**指令界面**

### 功能说明
1. **表达式求值**：按填写的运算表达式算出一个新值，写入「保存结果变量」。
2. **不改源变量**：表达式里出现的变量只被读取，本身不会被改掉。

### 参数解析
1. **开关**：最多 4 路同时配置。没勾选的路不会执行。
2. **运算表达式**：支持加、减、乘、除和括号。例如 `HP-10`、`(A+B)*2`。
3. **保存结果变量**：用来存放这次算出来的值。想改原来的变量，就把结果变量填成同一个名字。
4. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **结果变量**：运算式里写了 `HP`，但结果变量填的是 `HP2`，则 `HP` 还是原值，新值在 `HP2`。
2. **变量名**：结果变量同样不能为空、不能是纯数字、不能包含 `_`。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`运算序号`，带备注时为 `运算序号_备注`
- 示例：`运算1`、`运算1_HP减伤`
