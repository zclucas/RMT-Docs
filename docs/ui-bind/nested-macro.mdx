---
title: "5. 嵌套宏容器"
sidebar_position: 6
---
以下容器可在挑选器中展开。容器里的步骤使用相同字段白名单，绑定会保存完整嵌套路径。

| 指令 | 可展开内容 |
|---|---|
| 如果 | 真分支、假分支 |
| 如果Pro | 分支 1 至 N、默认分支 |
| 循环 | 循环体 |
| 搜索 / 搜索Pro / 搜索Combo / 组合搜索 / 搜索Multi | 真分支、假分支 |

嵌套最多 5 层。步骤或容器被修改、删除后，原绑定路径可能失效；失效路径会报出提示，不应继续写入旧位置。宏操作引用子宏的方式不稳定，因此不会递归展开其目标宏。
