title: "📌 使用说明"
sidebar_position: 2
---
先正常打开一次若梦兔。软件会把程序路径写入环境变量 `rmt`，并把 `rmt` 命令加入当前用户的 PATH。之后**重新打开终端**，在任意目录都可以直接输入命令。

| 项目 | 说明 |
|------|------|
| 🔤 **环境变量 `rmt`** | 程序完整路径。编译版是 exe，源码运行时是启动脚本。 |
| 🖥️ **命令 `rmt`** | 新开的终端里直接使用，不必先进入软件目录。 |
| 🔢 **位置 `m-n`** | 第 `m` 个页签里的第 `n` 个宏，从 **1** 开始。例如 `1-2` 是第 1 页第 2 条宏。 |
| ✅ **退出码 `0`** | 执行成功。查询类命令的结果写在标准输出。 |
| ❌ **退出码 `1`** | 参数不对，或页签、宏、变量、数组不存在。原因写在标准输出。 |
| ⏱️ **退出码 `2`** | 若梦兔没能及时启动，或指令等待超时。 |

> 若梦兔已经打开时，命令交给当前实例执行，不会把正在运行的宏关掉。若梦兔没打开时，命令会先把软件拉起来，再执行。

> 管理员身份运行编译版时，同名变量还会写入系统环境变量。

值里含有空格时请加引号：

```bat
rmt -set 标题 "第一行 内容"
```
