---
title: "抓图 / 搜图失败（OpenCV）"
sidebar_position: 8
---
抓图指令或搜索图片时报 OpenCV 不可用、dll 加载失败，或抓完 `Images\TempShot` 里没有图。

**原因：**
- 未解压完整、杀毒删了 `Plugins/OpenCV`
- 测试版（版本号带 F）和正式资源对不上
- 把「抓图」失败当成要改设置里的「截图方式」（抓图不走这项）

**解决方法：**
- 设置 → 文件校验，补齐 OpenCV 插件
- 从 GitHub / Gitee 发行版重新下载完整包
- 抓图看 `Setting\<当前方案>\Images\TempShot`；安装目录没写权限时看用户临时目录 `RMT_TempShot`
- 工具热键截图、RMT指令「截图」报错，才去设置里换微软 / RMT / SC
