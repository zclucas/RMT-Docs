**指令界面**

![配置界面](/img/1.3/MacroCMD/Key.png)

### 功能说明
1. **按下 / 松开 / 点击**：对界面里勾选的那些键，执行对应动作。
2. **组合键**：可以同时勾选多个键。执行时按勾选顺序一起按下；松开时按相反顺序抬起。

### 类型说明
1. **按下**：按下指定按键后立刻继续下一条（瞬发，本条不消耗时间）。
2. **松开**：松开指定按键后立刻继续下一条（瞬发）。
3. **点击**：先按下，等待「点击时间」后再松开；可以连续重复多次。

### 参数解析
1. **类型**：按下 / 松开 / 点击。只有选「点击」时，下面三项才生效。
2. **点击时间**：从按下到松开经过的时间（毫秒）。省略时默认 `100`。
3. **点击次数**：连续点击多少次。省略时默认 `1`。
4. **每次间隔**：松开之后、下一次再按下之前的等待（毫秒）。省略时默认 `0`。只在点击次数大于 1 时有意义。

### 特别说明
1. **瞬发**：按下、松开执行完立刻走下一条，本条本身不等待。
2. **不是连发**：选「按下 `a`」只是把 `a` 按住，不会像物理键盘长按那样自动反复输入 `a`。系统长按时，其实是在不断松开再按下；本指令不会这么做。
3. **配对松开**：用「按下」之后，建议后面再配一条「松开」。只按不松就再按一次，后续按下可能无效（卡键）。
4. **点击与长按**：这不是本指令里的两种类型，而是目标程序怎么理解这次按住。多数程序里，点击时间短于约 200ms 会被当成单击，长于约 250ms 会被当成长按；200～250ms 介于两者之间，表现因软件而异。
5. **点击耗时**：本条实际占用的时间 ≈（点击时间 + 每次间隔）× 点击次数 − 每次间隔。最后一次松开后不会再等「每次间隔」。
6. **浮动**：点击时间受设置「点击时间浮动(%)」影响；每次间隔受「每次间隔浮动(%)」影响。按下、松开是瞬发，不受点击时间浮动影响。这两项也不是「间隔指令浮动」。
7. **结束松键**：这里说的是宏的**触发类型**（按下 / 松开 / 双击 / 长按 / 开关），不是本指令的按下 / 松开 / 点击。触发类型为按下、松开、双击、长按时，宏**正常跑完不会**自动松开仍按住的键。只有被终止，或触发类型是**开关**并结束时，才会兜底松开。因此「只按下不松开」在开关宏里看起来没事，换其它触发类型就容易卡键。
8. **宏设置 · 按键类型**：本指令不选择模拟方式，发送走的是该条宏「宏设置」里的按键类型。
   - **AHK Send**：通用，适合办公和多数游戏（管理员权限可让更多游戏有效）
   - **keybd_event**：系统接口，适合老软件或游戏（需管理员）
   - **罗技**：走罗技驱动（需管理员，G HUB 需为 2022.2.1154 及以前版本）
   - **AHI**：走 Interception 驱动（需管理员，并安装 Interception）
   记事本能触发、游戏里无效时，优先勾选「管理员启动」，再改这条宏的按键类型，而不是改本指令的点击时间。
9. **按下时按下**：宏已经把某键按住，又执行一次「按下」时，由设置「按下时按下」决定：自动松开（默认，先松再按）、忽略重复按下、允许重复按下（罗技模式可能卡死）。
10. **自触发**：keybd_event、罗技、AHI 模拟出的键可以作为宏的触发键。触发键不要和本指令输出的键相同，否则会自己触发自己形成死循环。
11. **点击时间建议**：建议不低于 **100ms**，低于 **30ms** 时后续指令容易丢失。不追求极限速度时，点击后再加一条间隔更稳。
12. **手柄**：键盘鼠标用本指令。虚拟手柄请用「手柄」指令。

### 键盘按键检测
1. 点击界面上的输入框。
2. 按下要模拟的目标按键或组合键。
3. 点击「确定」，软件会自动勾选对应按键，不必在列表里一个个找。

### 指令格式
- 按下：`按键_按键名_按下`
- 松开：`按键_按键名_松开`
- 点击：`按键_按键名_点击_点击时间_点击次数_每次间隔`
- 多键：键名之间用 `⎖` 连接，例如 `按键_Ctrl⎖a_点击_100`
- 示例：`按键_a_按下`、`按键_a_点击_100`、`按键_a_点击_100_10_200`
