**指令界面**

### 功能说明
1. **变换文本**：对某个变量里已有的文本做分割、提取、替换、去空格、改大小写、统计或拼接。
2. **写出结果**：把处理后的结果保存到变量或数组，不会改掉来源变量（除非结果也写成同一个名字）。

### 类型说明
1. **文本分割**：按分隔文本切开、按固定长度切开，或按正则切开。
2. **文本提取**：从文本里抽出数字、字母、中文，或按正则抽出匹配部分。
3. **文本替换**：查找并替换。可以按普通文本匹配，也可以按正则匹配。
4. **去除空格**：去掉前面、后面、前后两侧，或去掉全部空白字符。
5. **大小写转换**：全部大写、全部小写，或只把首字母改成大写。
6. **文本统计**：统计字符数、单词数或行数，结果是一个数字。
7. **文本拼接**：在来源文本后面再接上一段内容。

### 参数解析
1. **文本来源**：要从哪个变量读取原文。
2. **类型选项 / 类型参数**：随上面的处理类型变化，例如分隔符、每段长度、查找文本、替换文本、正则。
3. **保存类型 / 名称**：结果写入变量还是数组。分割后通常是多段，适合保存到数组。
4. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **分割结果**：切开后一般是多段，通常保存到数组，再用「数组」指令按位置取值。
2. **源变量**：来源变量不存在时，本条整条无效，不会写出结果。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`文本处理序号`，带备注时为 `文本处理序号_备注`
- 示例：`文本处理1`、`文本处理1_按逗号拆`
