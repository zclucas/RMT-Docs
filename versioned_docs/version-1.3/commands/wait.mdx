### 功能说明
反复检测指定条件，条件满足后继续执行下一条指令。适合等待窗口、文件或界面状态变化，避免只用固定间隔猜测完成时间。

### 类型说明
- **变量**：等待变量值等于期望值。
- **按键**：等待指定键按下或松开。
- **屏幕与鼠标**：等待屏幕变化、鼠标移动或鼠标停止移动。
- **剪切板**：等待剪切板文本变化。
- **进程**：等待进程存在或关闭。
- **窗口**：等待窗口存在、激活、屏幕变化、大小变化、关闭或最小化。
- **文件**：等待文件存在、删除或变化。
- **日期**：等待指定日期或时间，支持分钟、小时、天、具体时间和时间变量。

### 参数解析
1. **等待类型**：选择要检测的条件，共 19 种；界面按类型显示所需参数。
2. **条件参数**：按类型填写变量名与期望值、按键、进程名、窗口信息、文件路径或日期。
3. **检测范围**：屏幕变化类条件使用起止坐标；框选后确认范围只覆盖需要监测的区域。
4. **检测间隔**：每次检查之间的毫秒数，受设置中的「每次间隔浮动」影响。
5. **备注**：便于辨认等待用途。

### 特别说明
- 变化类条件以执行到本条时的状态为基准，等待之后发生的变化。
- 鼠标停止移动以连续 3 次轮询位置不变为满足条件，因此检测间隔会影响判定时间。
- 条件一直不满足时会持续等待；可通过宏的暂停或终止操作控制。本指令没有单独的超时参数。
- 固定暂停用「间隔」，时间等待与倒计时可用「时间」，需要人工确认则用「等待确定」。

### 指令格式
- 参数保存在配置中，宏中写 `等待序号` 或 `等待序号_备注`。
- 示例：`等待1`、`等待1_等待下载完成`
