所属分类：键鼠/手柄

**指令界面**

![配置界面](/img/1.3/MacroCMD/Mouse.png)

### 功能说明
1. **后台点击**：向指定窗口发送鼠标消息，真实光标不会移过去。
2. **可滚轮**：除了左 / 中 / 右键，也可以发垂直或水平滚轮消息。

### 类型说明
1. **点击 / 双击 / 按下 / 松开**：对左、中、右键执行对应动作。选了滚轮时，这四项不会出现。
2. **滚轮**：按垂直 / 水平滚动量让目标窗口滚动，不会带动真实滚轮。

### 参数解析
1. **窗口信息**：按 `标题⎖类名⎖进程名` 匹配，可点「编辑」用鼠标选取。同时命中多个窗口时，会对每个窗口各发一次。
2. **鼠标按键**：左键、中键、右键、滚轮。
3. **操作类型**：点击、双击、按下、松开。选滚轮时没有这项。
4. **窗口坐标 X / Y**：相对该窗口客户区左上角，不是屏幕坐标。可填变量。受设置「坐标 X / Y 浮动」影响。
5. **垂直滚动 / 水平滚动**：仅滚轮时出现。垂直滚动量不是 0 时，只滚垂直，水平那一项不会再生效。
6. **点击时间**：仅点击、双击时出现，默认 `50` ms，表示按下到松开隔多久。
7. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **不是所有窗口都有效**：很多游戏、部分程序不接收后台鼠标消息。浏览器看起来点了但页面没反应时，通常是该窗口不支持后台，不是坐标填错。
2. **管理员**：部分窗口必须用管理员权限启动软件才有效。
3. **和前台移动 / 按键**：本指令走窗口消息，不移动真实光标，也不走宏设置里的 AHK / 罗技 / AHI。
4. **坐标变量**：X 或 Y 所用的变量取不到时，本条整条不执行。

### 快捷键
1. **F1**：同时填入鼠标下窗口信息（`标题⎖类名⎖进程名`）和窗口坐标。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`后台鼠标序号`，带备注时为 `后台鼠标序号_备注`
- 示例：`后台鼠标1`、`后台鼠标1_点确定`
