**指令界面**

![配置界面](/img/1.3/MacroCMD/Loop.png)

### 功能说明
1. **重复执行**：按指定次数，反复执行循环体里的那一段指令。
2. **条件控制**：可以在每一轮开始时先判断条件，再决定本轮要不要跑、或要不要离开循环。

### 类型说明
1. **无**：不设条件，只按「循环次数」执行。次数到了就结束。
2. **继续条件**：每一轮先判断。条件成立才执行循环体；不成立则离开循环。
3. **退出条件**：每一轮先判断。条件成立则立刻离开循环，不再执行本轮循环体。

### 参数解析
1. **循环次数**：循环体最多执行多少次。这是本指令自己的次数，不是宏配置上那个「循环次数」。
2. **循环条件**：无 / 继续条件 / 退出条件。可添加任意数量，比较方式和「如果」相同。
3. **逻辑关系**：多路条件之间用「且」（全部成立才算成立）或「或」（有一路成立就算成立）。
4. **循环体**：每一轮要跑的指令组合。
5. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **循环次数变量**：循环体里面可以用系统变量「循环次数」表示当前是本指令的第几轮。它和上面参数里的「循环次数」、宏配置上的「循环次数」不是同一个东西。
2. **跳转**：循环体中执行 `流程跳转_循环-跳过本轮` 会进入下一轮，执行 `流程跳转_循环-跳出` 会结束最近一层循环。需要条件判断时，把跳转放入「如果／如果Pro」的分支中。
3. **和外层循环**：宏配置上的「循环次数」是整条宏再从头跑几遍；本指令是宏内部再套一层循环。
4. **暂停 / 终止**：循环过程中可被暂停或终止打断。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`循环序号`，带备注时为 `循环序号_备注`
- 示例：`循环1`、`循环1_点十次`
