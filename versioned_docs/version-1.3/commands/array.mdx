### 功能说明
1. **列表数据**：创建、改写或查询一组按顺序排列的值。
2. **二维**：可以用子索引操作整个数组，或操作其中某一项（那一项本身还可以是数组）。

### 类型说明
1. **创建**：按填写的初始数据新建一个数组。
2. **克隆**：复制一份已有数组，得到另一个同内容的数组。
3. **删除**：删掉整个数组。
4. **包含**：判断数组里是否包含指定值或另一段数组，把是 / 否写入变量。
5. **取值 / 赋值**：按下标读出某一项，或改写某一项。
6. **插入 / 追加**：在中间指定位置插入，或在末尾追加。
7. **移除 / 移除最后**：按序号删掉一项，或删掉最后一个。
8. **反转**：把首尾对调，原来的第 1 个变成最后 1 个。
9. **长度**：把元素个数写入变量。

### 参数解析
1. **数组名**：要操作的数组。
2. **子索引**：`0` 表示操作整个数组（一维数组时保持 0）；填 `N` 表示操作第 N 项。数组元素的下标从 **1** 开始，和子索引的 `0` 不是同一套含义。
3. **参数**：随类型变化，可能是要写入的值、要查找的值，或下标。
4. **保存类型 / 名称**：取值、包含、长度等结果放在哪里。
5. **忽略已存在**：创建时如果这个数组名已经有了，可以跳过，避免把旧数组清掉。
6. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **下标从 1**：第 1 个元素的下标是 1，不是 0。子索引填 `0` 表示「整个数组」，不是「第 0 个元素」。
2. **输出展开**：输出指令里用 `{ε数组名}` 可以把数组内容展开成文本。
3. **全局**：数组和变量一样是全局的，所有宏共用同一个名字。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`数组序号`，带备注时为 `数组序号_备注`
- 示例：`数组1`、`数组1_建技能表`
