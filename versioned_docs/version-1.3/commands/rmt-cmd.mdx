所属分类：调控

**指令界面**

![配置界面](/img/1.3/MacroCMD/rabit.png)

### 功能说明
1. **调软件能力**：调用软件自己的功能，例如截图、自由贴、指令显示、菜单轮盘、休眠。
2. **调系统输入**：启用或禁用鼠标、键盘，或开关鼠标加速。这类操作多数需要管理员权限。

### 类型说明
1. **图文**：截图（保存到 `Images\ScreenShot`）、截图并提取文本（识别结果放进剪贴板）、自由贴（把剪贴板里的图片或文本贴到桌面上）。
2. **输入控制**：启用 / 禁用鼠标、键盘或键鼠一起；启用 / 禁用鼠标加速。都需要管理员权限，否则不会生效。
3. **宏控制**：显示菜单（可指定轮盘序号）、关闭菜单、暂停所有宏、恢复所有宏、终止所有宏。
4. **调试**：开启 / 关闭变量监视，开启 / 关闭指令显示。
5. **软件自身**：休眠、重载、关闭软件。

### 参数解析
1. **类别 / 指令**：从上面五类里选一项具体指令。
2. **菜单序号**：仅「显示菜单」需要，对应菜单宏里那个模块的序号。

### 特别说明
1. **休眠**：立刻终止全部宏，并禁用软件功能，和主界面上的休眠是同一件事。
2. **终止所有宏**：停掉之后不能再恢复，只能重新触发。
3. **重载**：重新加载已经保存过的配置。还没点「应用并保存」的改动会丢掉。
4. **禁用键鼠**：务必先留好恢复办法（后面再跑一条启用、或准备好热键），否则本机键鼠会被挡住。

### 指令格式
- 格式：`RMT指令_类别_指令`，「显示菜单」为 `RMT指令_宏控制_显示菜单_序号`
- 示例：`RMT指令_调试_开启指令显示`、`RMT指令_宏控制_终止所有宏`
